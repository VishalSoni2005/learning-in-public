⚡ Bellman–Ford Algorithm — Short Notes
✅ Where to Use
  Graph has negative edge weights (but no negative weight cycles).
  To detect negative weight cycles.
  Works on directed graphs only (if undirected graph non - negative edge use Dijkstra it is better as tc)

❌ Where Not to Use
  If graph is large and dense → it’s slower than Dijkstra.
  If only non-negative edges → prefer Dijkstra (faster).
  If graph has negative cycles → shortest path is undefined.

🛠️ How It Works
  Initialize distance of all nodes = ∞, except src = 0.
  Relax all edges N-1 times (where N = number of vertices).
  For each edge (u, v, wt) → if dist[u] + wt < dist[v], update dist[v].
  Run one more iteration to check → if distance can still be updated → negative cycle detected.

  ⏱️ Time Complexity
  O(V * E) → because for V-1 iterations, we check all E edges.
  Space: O(V) for distance array.
  👉 Slower than Dijkstra (O(E log V)), but works when Dijkstra fails.

🔑 What it does
  Finds shortest path from a single source to all other vertices in a graph.
  Works on directed/undirected graphs with non-negative edge weights.

⏱ Complexity
  Using min-heap (priority_queue): Time: O((V + E) log V)
  Space: O(V + E)

✅ When to Use
  Graph has non-negative edge weights.
  can work in directed cyclic graph 
  Need shortest path from one source.
  Graph is sparse (E ~ V or slightly more).

❌ When NOT to Use
  Graph has negative edge weights → use Bellman–Ford.
  Graph is very dense (E ~ V²) and small → adjacency matrix + DP may be better.


ONE THING TO HIT WHILE ANALYSING PROBLEM PATTER : 
  directed or undirected? Negative edges? One source or all-pairs?

# Greedy Algorithms Roadmap

**Arrays & Strings → Heaps → DP Hybrids → Graphs.**

If you cover all these patterns with the provided problems, you’ll be **highly confident in FAANG + top fintech interviews**.

- Go subtopic by subtopic.

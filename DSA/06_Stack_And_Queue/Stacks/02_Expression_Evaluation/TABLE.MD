| Conversion           | Key Points to Remember                                                                                                                                                                                          | Example (Input → Output)                            |
| -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------- |
| **Infix → Postfix**  | - Use **stack** for operators. <br> - Operands go directly to output. <br> - Pop operators with **higher/equal precedence** unless incoming is **right-associative** (`^`). <br> - Handle parentheses properly. | Infix: `A+B*C` <br> Postfix: `ABC*+`                |
| **Infix → Prefix**   | - Reverse infix string. <br> - Swap `(` and `)`. <br> - Convert to **postfix** using stack. <br> - Reverse result → prefix.                                                                                     | Infix: `(A-B/C)*(A/K-L)` <br> Prefix: `*-A/BC-/AKL` |
| **Postfix → Infix**  | - Use **stack of strings**. <br> - Traverse left→right. <br> - Operand → push. <br> - Operator → pop 2 operands, form `(op1 operator op2)`, push back.                                                          | Postfix: `AB+CD-*` <br> Infix: `(A+B)*(C-D)`        |
| **Prefix → Infix**   | - Use **stack of strings**. <br> - Traverse right→left. <br> - Operand → push. <br> - Operator → pop 2 operands, form `(op1 operator op2)`, push back.                                                          | Prefix: `*+AB-CD` <br> Infix: `(A+B)*(C-D)`         |
| **Postfix → Prefix** | - Traverse left→right. <br> - Operand → push. <br> - Operator → pop 2 operands (`op1`, `op2`), form `operator + op1 + op2`, push back.                                                                          | Postfix: `AB+CD-*` <br> Prefix: `*+AB-CD`           |
| **Prefix → Postfix** | - Traverse right→left. <br> - Operand → push. <br> - Operator → pop 2 operands (`op1`, `op2`), form `op1 + op2 + operator`, push back.                                                                          | Prefix: `*+AB-CD` <br> Postfix: `AB+CD-*`           |

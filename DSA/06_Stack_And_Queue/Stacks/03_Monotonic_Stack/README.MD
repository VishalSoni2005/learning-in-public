# 🧠 Monotonic Stack Cheat Sheet

A **monotonic stack** is a stack that is always either **increasing** or **decreasing**.  
You maintain it by popping elements that break the monotonic order when inserting a new element.

---

## 1. Monotonic Increasing Stack

- **Property:** Bottom → Top is strictly **increasing**.
- **Use Case:** Next Greater Element, Sum of Subarray Minimums, Histogram problems.

# Heaps (Priority Queues) – Interview Patterns & Subtopics

This document breaks down **Heaps** into subtopics and subpatterns commonly tested in FAANG + top fintech interviews.

---

## 1. Order Statistics (K-th Element & Selection Problems)

- **Min/Max-heap for K-th element (array, matrix, streams)**
- **K-closest values/points using heap**
- **Nearly sorted arrays (k-sorted)**
- **K-th smallest/largest sums and pair distances**
- **Two-heaps scoring / greedy scoring**
- **Heap-based selection in matrix / fraction problems**

---

## 2. K-Way Merge & Smallest Range

- **Merge K sorted lists/arrays**
- **Smallest range covering elements from multiple lists**
- **K-way merge in matrix / pair sums**
- **Connect sticks/ropes with min-heap (Huffman style)**
- **N max pair combinations (max-heap + set)**
- **Stream-based multi-way merge**

---

## 3. Top-K / Frequency / Proximity Problems

- **Top K frequent elements / words**
- **K closest elements (by distance, value)**
- **Greedy + heap for minimizing cost**
- **Stockpile/gift pile reduction with max-heap**
- **Halving arrays, minimizing deviation**
- **Proximity problems (sliding, range) with heaps**

---

## 4. Streaming & Two-Heaps Patterns

- **Median of data stream (two heaps)**
- **Sliding window median**
- **Seat reservation / resource allocation via heap**
- **Task assignment using servers (two heaps)**
- **Scheduling CPU tasks (single-threaded CPU)**
- **Eat-by-expiry (apples/food expiration)**
- **Minimum refueling stops (greedy with max-heap)**

---

## 5. Scheduling & Resource Allocation

- **Meeting rooms problems (allocate by end-time heap)**
- **IPO (profit + capital greedy with two heaps)**
- **Course schedule optimization (choose max duration heap)**
- **Task scheduler with cooldowns**
- **Attend maximum events (greedy min-heap)**
- **Skyline problem (sweep line + max-heap)**
- **Hiring workers with two heaps**
- **Process tasks with servers (load balancing)**

## 6. Heap Design & Canonical Implementations

- **Binary heap implementation (min-heap, max-heap)**
- **Indexed priority queue**
- **Lazy deletion heaps**
- **Custom comparators in heaps**

- **D-ary heap variations**
